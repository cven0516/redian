# 小店热点营销助手

> 你的店值得上热搜。10分钟出一个大牌级热点策划案。

## 这是什么

给请不起营销团队的小店用的热点借势营销AI助手。只要告诉它你的店在哪、卖什么、有什么困境，它就在10分钟内帮你：

- 🔥 扫描当前热点（抖音热榜、小红书趋势、本地活动、营销日历）
- 🎯 匹配最适合你的借势方向
- 💡 出2-3个策划概念让你选
- 📄 输出完整SMART策划案（内容矩阵+活动机制+投放策略+预算）
- 🎨 规划社交媒体视觉内容和线下物料
- 📊 生成可交互的HTML Dashboard策划看板

## 为什么需要它

你可能请不起营销团队，但你的店不应该因为这个就上不了热搜。大品牌花几万做一个借势活动，你用这个工具10分钟就能出一个同等水准的策划。

## 怎么用

```
"帮我的店看看最近能追什么"
"最近端午节快到了，我的咖啡店怎么蹭"
"帮我出个七夕方案"
"把策划思路做成看板"
```

## 核心原则

- **热点驱动** — 只做"这个热点×这个门店"的一个爆款
- **SMART可执行** — 每个产出都具体/可衡量/可达成
- **两次人工审核** — 方向选一次，策划选一次，不替你做所有决策
- **视觉有实物** — 出策划就配物料方案，不画饼

## 案例

**山月蛋糕 × 毕业季 → 「散伙糕」**

杭州原创蛋糕店，开了8个月小红书0粉丝。用本工具10分钟锁定毕业季方向，产出了「散伙糕」策划案——三款好意头蛋糕（一糕高中/折桂糕/好柿花生），全班拼单+每人送气球+蛋糕上印班级暗号，靠"隔壁班拼了我们也拼一个"裂变传播。总预算¥1,860。
